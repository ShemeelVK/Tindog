
## 🐶 Tindog – Dog Dating Website


## Description
Tindog is a landing page for a fictional dog dating website. It is built using HTML and Bootstrap to practice Bootstrap components and responsive design.

## 🚀  Features
• Attractive Landing Page – Clean and modern design using Bootstrap

• Pricing Plans – Different subscription options for users.

• Testimonials – Reviews from happy dog owners.

• Fully Responsive – Adapts to different screen sizes.

• Bootstrap Components Used:

     • Grid System
     • Buttons
     • Cards
     • Navbar
     • Responsive Layout

## 📂 Project Structure

```/Tindog
│── index.html       # Main HTML file  
│── css/style.css    # Custom CSS for styling  
│── images/          # Image assets (logos, icons, etc.)
```
